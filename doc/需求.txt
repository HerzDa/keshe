一、项目背景
传统中小企业报销存在发票真伪难辨、手工填写繁琐、单据不规范、重复录入等问题。本系统面向员工单角色，基于 Vue3 + Django + MySQL8.0 开发，集成百度智能云增值税发票验真 + 增值税发票 OCR 识别，实现先验真、再生编码、再回填、最后生成标准报销单的智能流程，降低操作成本，提升报销规范性，满足课程设计要求。
二、开发目标
实现员工单人全流程操作：登录 → 发票验真 → 6 位编码生成 → OCR 识别 → 自动回填 → 生成通用报销单 → 打印 / 导出 → 提交 → 查看历史。
基于 Vue3 + Django + MySQL8.0 完成前后端分离开发。
接入百度智能云 API，完成发票验真、信息结构化提取。
生成通用标准报销单，支持预览、打印、PDF 导出。
实现发票上传存储、编码唯一管理、个人报销记录、简单数据统计。
三、系统角色
仅一个角色：员工
登录 / 注册
发票上传验真
获取 6 位系统编码
报销信息填写、自动回填
生成通用报销单、打印 / 导出
提交报销、查看个人历史
个人数据统计
四、核心功能需求（最简可实现版）
4.1 登录与注册模块
员工注册：工号、姓名、密码、手机号
员工登录：工号 + 密码验证
退出登录
密码简单加密存储
4.2 发票验真模块（核心：先验真，不通过不往下走）
支持单张图片 / PDF 上传、拍照上传
后端调用 百度智能云增值税发票验真 API
验真结果：
验真不通过：提示假票 / 作废 / 红冲，不生成编码，禁止报销
验真通过：自动生成6 位唯一编码
6 位编码规则：年份后两位 + 4 位自增流水号（如：260001、260002）
发票图片重命名并保存到本地，路径存入数据库
发票信息、验真结果、编码绑定存储
4.3 发票 OCR 识别与自动回填模块
员工输入6 位编码，系统查询对应发票
后端调用 百度智能云增值税发票 OCR 识别 API
返回结构化字典数据，例如：
plaintext
发票代码、发票号码、开票日期、购买方名称、金额、税额、价税合计
一键自动回填到报销表单
支持手动修改识别错误内容
表单实时校验必填项
4.4 报销单填写与生成模块（通用模板）
员工补充填写：
报销部门、报销事由、报销日期
费用类型（办公 / 差旅 / 招待等）
备注信息
系统自动生成通用标准报销单，包含：
报销人、部门、日期、事由、费用类型
6 位系统编码、发票基本信息
金额（小写 + 大写自动转换）
审批签字区域（预留空白）
打印适配 A4、支持导出 PDF
4.5 草稿与提交功能
报销单可暂存为草稿，下次继续编辑
提交后状态改为 “已提交”
不可重复提交同一张发票
4.6 个人报销历史模块
列表展示：6 位编码、金额、提交时间、验真状态
支持查看详情、重新打印、重新导出 PDF
支持按时间 / 状态筛选
4.7 首页数据统计（加分项）
我的报销总笔数
验真成功发票数
报销总金额
最近报销记录
五、非功能需求
页面加载 ≤ 2 秒
验真 ≤ 2 秒，OCR 识别 ≤ 3 秒
编码查询回填 ≤ 1 秒
支持 Chrome、Edge 浏览器
数据存储安全，图片上传有格式校验
