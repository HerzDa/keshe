# 系统使用说明书

## 1. 登录注册
1. 打开登录页面。
2. 新用户先填写工号、姓名、手机号、密码完成注册。
3. 使用工号与密码登录。

## 2. 发票验真
1. 进入“发票验真/OCR”页面。
2. 选择发票文件并填写验真必要字段。
3. 点击“上传并验真”。
4. 若验真成功，系统显示6位编码；若失败，流程终止。

## 3. OCR识别回填
1. 输入6位编码。
2. 点击“OCR识别并回填”。
3. 页面显示OCR结构化结果并保存到本地缓存。

## 4. 填写报销单
1. 进入“填写报销单”。
2. 补充部门、事由、费用类型、日期、备注等字段。
3. 点击“保存草稿”或“提交报销”。

## 5. 打印与导出
1. 在报销页面点击“打印”调用浏览器打印。
2. 点击“导出PDF”生成报销单PDF文件。

## 6. 历史与统计
1. 在“首页统计”查看报销总笔数、验真成功数、总金额、最近记录。
2. 在“报销历史”按状态筛选查看历史报销单。
